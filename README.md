# 中国历史人物关系查询

一个可交互的中国历史人物关系图谱。**503 位人物、742 条关系**，覆盖先秦至清末民初，单文件、离线可用、零依赖。

打开网页即可使用，无需安装、无需登录、不发起任何网络请求。

## 功能

| 视图 | 说明 |
|---|---|
| **关系图谱** | 力导向布局，滚轮缩放、拖拽平移；单击人物查看生平与其全部关系，双击以其为中心展开；可按时代（7 组）与关系类型（14 种）筛选；支持导出 PNG |
| **关系链** | 输入任意两位人物，求最短关系路径，逐段给出关系类型与史实说明，并附一条备选路径与共同关联人 |
| **年代长卷** | 按生卒年横向铺开，人物以生卒区间色带呈现，时间轴范围随筛选自适应 |
| **人物库** | 全量表格，可按姓名 / 朝代 / 生卒排序、分页浏览，点姓名联动详情与图谱 |

## 示例

- 苏轼 → 林则徐：5 步（朱熹 → 王守仁 → 曾国藩 → 魏源 → 林则徐）
- 孔子 → 朱熹：14 步（子思 → 孟子 → 荀子 → 李斯 → 嬴政 → … → 董仲舒 → 朱熹）
- 李白 → 曹操：12 步

抽样 143 组人物对，连通率 **97.9%**，无孤立人物。

## 数据

- 人物字段：姓名、别号、生年、卒年、朝代、身份、简介
- 关系类型：亲属、婚姻、姻亲、宗亲、师承、君臣、同僚、政敌、敌对、盟友、交游、传承、举举、亲信、同列
- 生卒年以公元纪年表示，公元前用负数；部分人物生卒年史载不一，取通行说法

**数据说明**：人物关系依据通行史料整理，属科普与检索用途，不作学术引用之据。关系判定存在简化（如"同列"表示同类并称，"传承"表示思想或技艺上的承接），个别年份为约数。

## 技术

- 纯原生 HTML / CSS / JavaScript，无框架、无构建步骤、无 CDN 依赖
- 自研力导向布局（斥力 + 弹簧 + 中心引力 + 软碰撞），标签采用矩形防重叠放置
- 单文件约 127 KB，双击即可离线运行

## 本地使用

下载 `index.html`，用浏览器打开即可。地址后加 `#chain`、`#time`、`#list` 可直达对应视图。
